# PR / media intelligence

GrowthOS normalizes licensed or internal media data rather than inventing contacts.

## Contact object
Provider, provider external id, name, outlet, beat, email, profile URL, location, optional provider-derived influence score and provider metadata.

## Coverage object
Provider, external id, title, URL, outlet, author, body, topics, sentiment, optional linked GrowthOS content id and provider metadata.

## Target ranking
Target ranking is transparent: topic/beat overlap, imported influence signal and recent observed activity. It is not presented as a proprietary black-box media score.

## Provider strategy
Use licensed Cision/Muck Rack/Meltwater or other approved sources where contracted. Map their allowed fields into the normalized GrowthOS contracts. Provider terms, retention and contact-use restrictions remain authoritative.
