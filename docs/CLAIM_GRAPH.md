# Claim Graph

GrowthOS Claim Graph connects communications provenance and downstream observations for one governed release version.

Node types can include source, claim, release, delivery, earned-media observation, exact AEO citation match and performance summary. Edges describe `supports`, `approved-in`, `distributed-as`, `observed-in`, `cited-by` and `measured-by` relationships.

The graph is deliberately descriptive. A citation match does not prove that the answer engine learned the claim from that release. A conversion after publication does not prove causation. Chrysalis Lineage remains the causal-forensics component for deeper causal reconstruction.
